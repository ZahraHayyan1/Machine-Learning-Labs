# Machine-Learning-Labs

This repository contains my lab assignments for the **Machine Learning** course at Imam Abdulrahman Bin Faisal University.

## Topics Covered

The course covers the following topics:

* **Foundations of Machine Learning**

  * Linear algebra foundations
  * Linear maps and matrix operations
  * Data representation
  * Introduction to Machine Learning
  * Types of Machine Learning: supervised, unsupervised, and reinforcement learning
  * Machine Learning as function approximation

* **Machine Learning Workflow**

  * End-to-end Machine Learning pipeline
  * Predictive and descriptive models
  * Problem formulation
  * Real-world Machine Learning workflows
  * Reproducibility and documentation

* **Data Understanding and Exploration**

  * Numerical and categorical data
  * Exploratory Data Analysis (EDA)
  * Data visualization
  * Exploring distributions and relationships

* **Data Preprocessing**

  * Missing values
  * Noise and outliers
  * Encoding
  * Scaling and normalization
  * Data transformations
  * Introduction to Principal Component Analysis (PCA)

* **Feature Engineering and Selection**

  * Feature transformation
  * Polynomial features
  * Log transformations
  * Feature construction and extraction
  * Feature importance
  * Filter, wrapper, and embedded selection methods
  * High-dimensional data
  * Feature relevance and redundancy

* **Regression Models**

  * Linear Regression
  * Loss and error functions
  * Model optimization
  * Mean Absolute Error (MAE)
  * Mean Squared Error (MSE)
  * Root Mean Squared Error (RMSE)
  * R²
  * Ridge Regression
  * Lasso Regression

* **Classification with Logistic Regression**

  * Logistic Regression
  * Decision boundaries
  * Probability interpretation
  * Confusion matrix
  * Accuracy
  * Precision
  * Recall
  * F1-score
  * Class imbalance

* **Distance-Based Models**

  * k-Nearest Neighbors (k-NN)
  * Distance metrics
  * Choosing the value of k
  * k-NN for classification and regression
  * Curse of dimensionality

* **Decision Trees**

  * Tree structure
  * Information Gain
  * Gini Impurity
  * Classification and regression trees
  * Overfitting
  * Pruning

* **Ensemble Learning**

  * Ensemble learning
  * Bagging
  * Random Forest
  * Boosting
  * AdaBoost
  * Gradient Boosting

* **Support Vector Machines**

  * Maximum margin
  * Hyperplanes and margins
  * Kernel methods
  * Linear and non-linear SVM
  * Support Vector Regression (SVR)

* **Unsupervised Learning**

  * Clustering
  * K-Means clustering
  * Lloyd's algorithm
  * Choosing the number of clusters
  * Silhouette score
  * Hierarchical clustering
  * DBSCAN

* **Density Estimation and Gaussian Mixture Models**

  * Probability foundations
  * Expectation and variance
  * Maximum Likelihood Estimation
  * Density estimation
  * Multivariate Gaussian distributions
  * Gaussian Mixture Models (GMMs)
  * Expectation-Maximization (EM) algorithm

* **Model Evaluation and Optimization**

  * Training, validation, and test sets
  * Holdout validation
  * K-Fold Cross-Validation
  * Bootstrap
  * Underfitting and overfitting
  * Bias-variance trade-off
  * Gradient Descent
  * Stochastic Gradient Descent (SGD)

* **Introduction to Modern AI**

  * Introduction to Deep Learning
  * Introduction to Reinforcement Learning

## Repository Structure

Each lab is organized separately and includes the relevant code, notebooks, datasets, and supporting files.
